# Calibration summary

The graded calibration set contains four sealed parameter families, all different from the public practice case. The final reference artifact is required to pass all four families exactly. An independent implementation that shares no relation, Kronecker or barcode code with the reference reproduces all four sealed oracles exactly.

The hidden families use phase grids from 34 by 34 through 36 by 36 and parameter lattices between 210 and 225 parameters. Each family contains three long trajectories. Their lengths range from 2800 to 4800 parameter occurrences, giving up to 9599 endpoint bridge zigzag nodes. Across the twelve hidden trajectories, 98.3 to 100 percent of parameter-lattice edges are visited, immediate reversal rates are 0.47 to 1.45 percent, and the propagated Morse selection changes on 94.6 to 97.7 percent of steps. Propagated selections reach 25 Morse sets and the Morse reachability-graph H1 dimension reaches 333.

Every hidden query contains 384 Conley generalized-rank windows, the full Conley zigzag barcode in degrees 0, 1 and 2 (351 to 773 distinct intervals in each of H0 and H1), the full Morse-graph zigzag barcode in degrees 0 and 1 (6309 to 13797 distinct H1 intervals, total multiplicity up to 114565, with intervals spanning the whole trajectory), 128 Morse-graph generalized-rank windows, twenty Conley closed loops, ten Morse-graph closed loops, ten Conley holonomy probes and six graph holonomy probes. Each probe is evaluated on fourteen relation words, four of which use converse relations. Every loop relation and every word relation carries its Kronecker invariants.

Loop windows and probes are selected for structural coverage. Every hidden family contains right minimal indices, left minimal indices, infinite elementary divisors and finite elementary divisors, including nilpotent blocks (divisor x) and identity blocks (divisor x+1), and every hidden family contains compositions that pass through the zero relation and become nonzero again. The public example contains all of these as well.

All scientific quantities are exact integers over F2. The verifier therefore requires exact equality for transported selections, node dimensions, sparse rank records, barcodes, loop signatures, and holonomy-word signatures. Passing requires all four sealed families.

Ablations (`run_ablation_checks.py`, report in `ablation_report.json`) cover greedy single-branch transport, endpoint-dimension rank inference, identity loop transport, removal of the Morse-graph layer, removal of the holonomy layer, the retired absorbing-zero shortcut (`zero_shortcut_variant.py`), graph-only Kronecker classification, collapsing singular Kronecker blocks, omission of converse words, omission of barcodes and barcodes read from node dimensions. Each fails all four hidden families. Local anti-cheat checks separately exercise empty output, case-id-only output, sealed-oracle snooping, and symbolic-link output.

The Morse-graph barcode is the runtime discriminator. Sweeping a composed relation from every start node would need 15.7 to 46.1 million compositions of relations on spaces of dimension up to 333 per query, far beyond the 300 second limit, while a single flag sweep takes about 12 seconds for the largest query. The `graph_barcode_capped_sweep` ablation shows that truncating per-start sweeps to fit the budget fails every hidden family.
