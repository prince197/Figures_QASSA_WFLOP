\section{Hybrid LX-SSA-VNS Algorithm}
\label{sec:hybrid}
Population-based swarm methods such as LX-SSA spread their search over many regions of the layout space, but once the swarm has contracted around the food source, most remaining evaluations produce only small improvements. Trajectory-based local search behaves the other way round. Variable neighbourhood search (VNS)~\cite{Mladenovic1997,Hansen2001} refines one incumbent systematically by alternating random perturbations of increasing size with a complete local search, but its result depends strongly on where it starts. This complementarity motivates a two-phase hybrid, LX-SSA-VNS, in which the previously published LX-SSA~\cite{Solanki2023} provides global exploration and the original basic VNS provides intensification.

\subsection{Phase 1: Global Exploration by LX-SSA}
For a budget of $B$ objective calls and a split fraction $\rho\in(0,1)$, LX-SSA (Algorithm~\ref{alg:lx-ssa-wflop}) runs with population $N_p$ for
\[
T_1=\operatorname{round}\!\left(\frac{\rho B-N_p}{2N_p}\right)
\]
iterations, because one LX-SSA iteration costs $2N_p$ calls. Its parameter $r_1$ decreases over these $T_1$ iterations, so the swarm moves from exploration to exploitation within Phase~1. The food source $H$ at the end of Phase~1 is the starting incumbent of Phase~2.

\subsection{Phase 2: Intensification by Basic VNS}
Phase~2 is the basic VNS of Mladenovi\'c and Hansen~\cite{Mladenovic1997,Hansen2001} in the continuous form of Mladenovi\'c et al.~\cite{Mladenovic2008}, applied to the penalized objective $F_p$~\eqref{eq:penalty}. It uses $k_{\max}=5$ nested $\ell_\infty$ neighbourhoods of the whole layout,
\[
\mathcal N_k(x)=\{y:\rho_{k-1}<\lVert y-x\rVert_\infty\le\rho_k\},\qquad \rho_k=0.1\,k\,r .
\]
\begin{itemize}
\item \emph{Shaking} draws a point uniformly from $\mathcal N_k(x)$, so all $2N$ coordinates move; box repair is applied.
\item \emph{Local search} is a complete best-improvement descent to a local minimum. Because the Jensen top-hat wake makes $F_p$ discontinuous, a derivative-free compass search is used: it evaluates all $4N$ moves $\pm h$ along the coordinate axes, moves to the best improving one, and halves $h$ (starting from $0.05r$) when none improves, until $h<10^{-3}r$.
\item \emph{Neighbourhood change}: if the local minimum improves on the incumbent, it is accepted and $k\gets1$; otherwise $k\gets k+1$, and $k\gets1$ after $k_{\max}$.
\end{itemize}
Phase~2 first applies the local search to $H$ and then repeats shaking, local search and neighbourhood change until the budget $B$ is exhausted. It returns the best layout evaluated. Box repair and the penalized objective are used exactly as in LX-SSA, so the feasibility-first rules of Section~\ref{sec:constraints} apply in both phases.

\begin{algorithm}
\caption{Hybrid LX-SSA-VNS for a prescribed turbine count $N$}
\label{alg:hybrid}
\begin{algorithmic}[1]
\Require budget $B$, split $\rho$, population $N_p$, LX-SSA parameters $\phi,\chi$, farm radius $r$
\State $T_1\gets\operatorname{round}((\rho B-N_p)/(2N_p))$
\State Run LX-SSA (Algorithm~\ref{alg:lx-ssa-wflop}) for $T_1$ iterations; let $H$ be its food source
\State $x\gets\textsc{LocalSearch}(H)$; $k\gets1$
\While{fewer than $B$ objective calls have been used}
    \State $y\gets$ uniform random point of $\mathcal N_k(x)$; box repair
    \State $y\gets\textsc{LocalSearch}(y)$
    \If{$F_p(y)<F_p(x)$}
        \State $x\gets y$; $k\gets1$
    \Else
        \State $k\gets k\bmod k_{\max}+1$
    \EndIf
\EndWhile
\State \Return best layout evaluated
\Statex
\Function{LocalSearch}{$y$} \Comment{compass search, best improvement}
    \State $h\gets0.05r$
    \While{$h\ge10^{-3}r$}
        \State $z^\star\gets\arg\min F_p$ over the $4N$ points $y\pm h\,e_i$ (box-repaired)
        \If{$F_p(z^\star)<F_p(y)$} \State $y\gets z^\star$ \Else \State $h\gets h/2$ \EndIf
    \EndWhile
    \State \Return $y$
\EndFunction
\end{algorithmic}
\end{algorithm}

\subsection{Parameters and Cost}
The hybrid uses $N_p=30$, $\phi=0$, $\chi=1$ and the VNS settings above, and it has a single new parameter, the split $\rho$. The default $\rho=0.5$ assigns 3,030 of the 6,030 calls to LX-SSA ($T_1=50$) and the remaining 3,000 to VNS; its sensitivity is examined in Section~\ref{sec:ablation}. The per-call cost of both phases is dominated by the objective evaluation, so the hybrid has the same $\mathcal O(B\,N^2N_\theta N_s)$ cost as the other methods for a budget of $B$ calls. Because the random-number generator is seeded once and Phase~1 draws the initial population first, for a given seed the hybrid starts from the same initial population as all other methods, which keeps the comparisons paired.
