**How GA enters.**
- **Lillgrund pools.** GA is added after DE to the pool of the existing tables, `SP9` = the nine methods including the control RSD-VNS, giving 10 methods. PSO-VNS therefore has 9 comparisons per budget instead of 8, following the Horns Rev pattern (pool of 11).
- **Re-evaluation.** The GA layouts are re-evaluated with the identical code: 5° replay, 1° bins centred at 0.5°, and PyWake 2.6.20 NOJ with k = 0.04 at the 1° bins.
  - GA's MinSpacing comes from its own records, for the ordering of infeasible runs.
  - GA's coordinates have 17 significant digits, so its 5° replay equals the stored AEP: the difference is 0 after `%.10g`.

## 4. Integration notes

- **S-tab:S-xp-site** is an inline table, not captured. To use the new version:
  1. Capture `analysis/rev5_ga_sites_tables.tex` after `rev3_sites_tables.tex`. A later capture of a label replaces the stored body, as is already done with `rev5_ga_tab_robust_supp.tex`.
  2. Replace the inline `\begin{table}...\label{tab:S-xp-site}...\end{table}` with `\SuppTable{tab:S-xp-site}`.

  The same capture also replaces S-sa-lg-eval.
- **`rev5_ga_inference_tables.tex` and `rev5_ga_dependence_tables.tex`** hold only the replaced table. Capture each after its original.
- **`rev5_ga_archive_reliability_tables.tex`** is a complete file for the `\input` of `archive_reliability_tables.tex`.
- **Copies.** The `.tex` files must be copied to `latex_source/analysis/` to be used; that was not done here.
