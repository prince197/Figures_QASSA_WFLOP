# R7 — Reproducibility review (text vs. code)

Scope: optA/03_model.tex, 04_methods.tex, 05_setup.tex, 08_beyond.tex, 11_back.tex (Data Availability) against
analysis/*.py and build_mpce_paper.sh. Line numbers refer to the files in analysis/ as of 2026-09-28.

## Empirical checks performed (all pass unless stated)

- **PSO-VNS = PSO up to the switch.** I ran a tiny case (DS I, r=500, N=3, seed 1; DS II, r=1000, N=6, seed 7) with
  `PSO(30,200,constriction)` and `HybridBVNS(...,"PSOC")` and logged every evaluated vector: the first 3,030
  evaluated layouts are **bit-identical**, and call 3,031 differs (VNS starts). `iters1 = 100`, `phase1_calls = 3030`.
  Archived data agree too: in all 2,040 benchmark pairs (mpce_psoc vs mpce_psobv) and all 30 Horns Rev pairs
  (mpce_hr16new PSOC vs mpce_psobv HR) the first 101 convergence checkpoints (calls 30…3,030) are identical.
- **Bitwise re-run of archived runs with the current code** (DS I, r=500, N=5, seed 3, 6,030 calls): SSA-VNS,
  LX-SSA-VNS, VNS (fresh_*), LX-SSA, DE, old-setting PSO (fresh_grid), PSO, PSO-VNS, RS-VNS, MS-SLSQP (mpce_*)
  all reproduce objective and coordinates exactly. **Exception:** MS-SLSQP on Horns Rev 16 seed 1 (fresh_hr16.csv)
  does not reproduce (archived 137.519 GWh, re-run 137.391 GWh) — see finding 17.
- **Call counts:** every row of every per-run file has Calls = Budget exactly (6,030 / 30,030 / 120,030).
- **Seed pairing:** in fresh_grid.csv the first checkpoint (best of the initial population) is identical across all
  methods for every case × seed.
- **Iteration arithmetic:** stand-alone PSO/SSA/DE `it1 = (B−Np)//Np = 200`, LX-SSA `(B−Np)//(2Np) = 100`
  (mpce_experiments.py:65,80); hybrids `round((ωB−Np)/per_iter)` (hybrid_lxssa_bvns.py:224) → PSO/SSA 100
  (3,030 calls), LX-SSA 50 (3,030 calls); ω=0.25 → 49 PSO iterations (1,500 calls), ω=0.75 → 150 (4,530 calls);
  RS-VNS `round(ωB) = 3,015` (rs_vns.py:140).
- **Validation numbers:** validate_evaluator.py reproduces 720 records, max |ΔObj| = 8.73e-11; calibration_vs_recorded.csv
  has 22 of 24 p ≥ 0.05. Container versions are Python 3.11.15, NumPy 2.4.6, SciPy 1.17.1 as stated.
