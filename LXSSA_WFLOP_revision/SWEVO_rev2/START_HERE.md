# Revised SWEVO package — second revision (internal: revision 3), 4 October 2026

This package contains the second revision of the SWEVO manuscript (internal name revision 3; in the documents
"first revision" = internal revision 2, "this revision" = internal revision 3). The research archive is **complete**: the 36,190
original run records, the 11,640 revision-2 records and the revision-3 records are in the repository together with
all model, optimizer, driver, analysis and check scripts. The revision-2 statement that the original records and
fifteen core modules were missing was wrong (they are in `analysis/`). For revision 3 the complete analysis pipeline
was re-executed from a deposit-ready reproducibility package (`repro_package_build/`). Release 1.0.0 of the package
contains all records, including the 5,100 revision-3 runs and the full-precision reruns (5,714 records + a 30-record determinism sample). It was verified from a
clean unpack: all checksums pass, all regenerated outputs are identical to the stored ones apart from time stamps,
all automated checks pass, and reruns of stored gradient-free runs are bit-identical except for the elapsed time
(SLSQP-based runs are not bit-reproducible across CPU/BLAS builds). The archive is
`repro_package_build/dist/SWEVO_repro_1.0.0.zip` (rebuild with `sh repro_package_build/make_package.sh 1.0.0`).

Open before submission (author actions only; details in `AUTHOR_CONFIRMATION.md`):

  eligibility (cover letter), agreement on the primary equivalence questions.

and work items A–E to the changes. Search the sources for `\TBD` to find every value still to be supplied; each one
prints in red in the PDFs.

## Reproduce the results

See `latex_source/analysis/README_reproduce.md` (short guide) and `repro_package_build/README.md` (full map from
every table, figure and number to its command, inputs and run time). In the unpacked package:

```sh
sha256sum -c MANIFEST.sha256
python -m pip install -r requirements.txt     # CPython 3.11.15, NumPy 2.4.6, SciPy 1.17.1, pandas 3.0.6
sh regenerate_all.sh /tmp/regen               # regenerates and compares all outputs, runs all checks
```

`SWEVO_rev2/requirements-audit.txt` only pins the revision-2 standalone audit environment. The run environment is
`repro_package_build/requirements.txt`.

## Build the documents

Use TeX Live with `elsarticle`, `algorithms`, `algorithmicx`, `lmodern`, `lineno`, `environ`, `placeins` and the
standard AMS/graphics packages:

```sh
sh latex_source/analysis/build_swevo.sh
```

The build needs no BibTeX step; the references are a manual `thebibliography` in order of first citation. After
citations change, run, from `LXSSA_WFLOP_revision/`, `python3 analysis/rev3_bib_order.py
SWEVO_rev2/latex_source/SWEVO_manuscript.aux SWEVO_rev2/latex_source/optA/swevo_back.tex` (the .aux of a completed
build), then rebuild. The build refreshes the cross-document labels (`xref/`) and the single-file manuscript.
