SWEVO manuscript sources
========================

Main document:  SWEVO_manuscript.tex (preamble manuscript_preamble.tex; front matter optA/swevo_front.tex; sections
                optA/sw/*.tex; back matter and references optA/swevo_back.tex).
Single file:    SWEVO_manuscript_full.tex is the same manuscript flattened into one file (generated by the build).
Supplement:     SWEVO_supplement.tex. Cover letter: SWEVO_cover_letter.tex. Declarations: SWEVO_declarations.tex
                (text in declarations_content.tex). Highlights: SWEVO_highlights.txt.
Tables, number macros and figures are in analysis/, figures_mpce/ and figures_final/; cross-references between the
manuscript and the supplement are in xref/.

Build (TeX Live with elsarticle, algorithms, algorithmicx, lmodern, lineno, environ, placeins):
    sh analysis/build_swevo.sh
On Overleaf: set SWEVO_manuscript.tex (or SWEVO_manuscript_full.tex, or SWEVO_supplement.tex) as the main document.
