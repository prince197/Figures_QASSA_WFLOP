Verification of the SWEVO reproducibility package
=================================================

The package was verified in two steps:
  Verification 1 (records of the main study and the additional experiments), 2026-10-04;
  Verification 2 (complete package, release 1.0.0), 2026-10-05
=============================================================

In addition to the content checked by Verification 1, the complete package contains: the 5,100 runs of the
sensitivity studies (constraint handling 2,700; direct 1-degree optimization 1,200 and its 15-degree control arm
1,200), the 5,744 full-precision reruns (raw rev3_precision_results/*.jsonl, merged rev3_fullprec_<study>.csv) with
the 35 cloud worker logs, the sensitivity analyses (including rev3_dependence.py: seed-level all-run inference and
joint-seed TOST calibration; rev3_feasbounds.py: bounds, tolerance sensitivity and worst case of the undecided
feasibility labels, rounding sensitivity of re-evaluations), their tables and the prespecifications, the eight
superseded run files covered by the precision audit, and the corresponding steps of regenerate_all.sh.

Procedure (same environment as Verification 1): make_package.sh 1.0.0; the zip was unpacked into an empty scratch
folder; sha256sum -c MANIFEST.sha256: 804 of 804 files OK (release_1.0.0/manifest_check.txt); then
    WITH_SLOW=1 WITH_DETERMINISM=1 WITH_PYWAKE=1 MANUSCRIPT=<SWEVO latex_source, state of 2026-10-05> sh regenerate_all.sh <scratch>
in the unpacked package: 32 steps, total 4,069 s (rev3_inference.py with its null calibrations 2,930 s on the shared
machine) (release_1.0.0/steps.txt). 31 steps exited with 0; rev3_dependence.py stopped because regenerate_all.sh did
not copy SWEVO_rev2/validation/ (a reference file it reads) into the scratch folder. regenerate_all.sh was corrected
(it now copies SWEVO_rev2/validation and SWEVO_rev2/experiments_docs into the scratch folder) and the step was rerun
in the same scratch folder: exit 0, 470 s (release_1.0.0/rev3_dependence_rerun.log).

Comparison (release_1.0.0/compare.txt and the rerun): 208 regenerated files compared with the stored copies,
170 byte-identical, 38 identical after removing generation time stamps / PDF dates / run-time fields / environment
versions only, 0 different, 0 missing. They include the 117 outputs of the sensitivity studies, sensitivity analyses
and full-precision reruns (112 byte-identical, 5 after normalization): rev3_inference, rev3_dependence,
rev3_constraint, rev3_fine, rev3_sites, rev3_feasbounds (json and tables; rev3_feasbounds also with the PyWake
re-evaluations), rev3_precision_audit (json and records), rev3_precision_rerun_summary.json, rev3_precision_tables.tex
and every rev3_fullprec_*.csv.

Checks: CHECK-FINAL 62 PASS / 0 FAIL / 0 PENDING / 0 tag errors on the manuscript sources (state of 2026-10-05); X01-X57,
D01-D22, F01-F46 (41 checks), S01-S15 and T01-T13 (57) all pass; audit_archive.py and check_revision.py pass;
determinism: 4 of 4 reruns bit-identical to the stored records (all fields except Seconds).
