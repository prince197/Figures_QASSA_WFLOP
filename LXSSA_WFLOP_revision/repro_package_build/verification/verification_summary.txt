Verification of the SWEVO reproducibility package, release 1.0.0 (2026-10-07)
==============================================================================

Environment (Section 3 of the README): CPython 3.11.15, NumPy 2.4.6, SciPy 1.17.1, pandas 3.0.6, Matplotlib 3.11.2,
PyWake 2.6.20, Linux x86_64 (Ubuntu 24.04), shared multi-core machine, one worker process per step.

Procedure. make_package.sh 1.0.0 built the archive; it was unpacked into an empty scratch folder and
    sha256sum -c MANIFEST.sha256                                    775 of 775 files OK (release_1.0.0/manifest_check.txt)
    WITH_SLOW=1 WITH_DETERMINISM=1 WITH_PYWAKE=1 MANUSCRIPT=<SWEVO latex_source> sh regenerate_all.sh <scratch>
was run in the unpacked package: 33 steps, every step exit 0, total 2,735 s (rev3_inference.py with its null
calibrations 1,877 s; rev3_dependence.py with the joint-seed calibration 334 s) (release_1.0.0/steps.txt).

1. Run records (count_records.py): 36,190 records of the main study, 11,640 of the additional experiments
   (GA 2,040 + 60 + 120, exact gradients 240, Laplace ablation 2,160, spacing 6,480, Lillgrund 270 + 270) and the
   records of the sensitivity studies (5,100 runs) and of the full-precision reruns (5,744), as stated in the article.

2. Regenerated outputs compared with the stored copies (release_1.0.0/compare.txt): 211 files, 173 byte-identical,
   38 identical after removing only generation time stamps, PDF creation dates, gzip header times, run-time fields and
   recorded environment versions; 0 different, 0 missing. They comprise the tables, number macros, summaries,
   statistics files and figures of the main pipeline (mpce_results.py, mpce_inference_extra.py, mpce_direction.py,
   mpce_csweep.py), of the additional experiments (rev2_analysis.py, audit_archive.py, check_revision.py), of the
   sensitivity analyses and full-precision reruns (117 files: rev3_inference, rev3_dependence, rev3_constraint,
   rev3_fine, rev3_sites, rev3_feasbounds incl. the PyWake re-evaluations, rev3_precision_audit, the merged
   full-precision rerun files and their summary and table), the theory and model figures and the graphical abstract.
   Not regenerated (stored, checked): the instrumented diagnostic reruns (mpce_diagnostics.py, ~18 min; checked by
   D01-D22); the robustness re-evaluation cache is reused.

3. Checks: CHECK-FINAL 62 PASS / 0 FAIL / 0 PENDING / 0 tag errors on the manuscript sources; X01-X57 57 PASS;
   D01-D22 22 PASS; F01-F46 41 PASS; S01-S15 15 PASS; theory checks T01-T13 57 PASS against the manuscript text;

   check_revision.py PASS (2,006 float round-trips, 140 raw CSV hashes).

4. Evaluator and model checks: validate_evaluator.py: 720 archived objectives of the original implementation,

5. Determinism (verify_determinism.py): seed 1 of the benchmark cases (DS I, r = 500 m, N = 6) and (DS II, r = 1000 m,
